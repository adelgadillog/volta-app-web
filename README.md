# Volta - Landing Page

Landing page oficial de Volta, una plataforma de fidelización digital para comercios y clientes.

## 🚀 Características

- **Diseño minimalista**: Paleta de colores oficial Volta (naranja primario)
- **Responsive**: Mobile-first, optimizado para todos los dispositivos
- **Despliegue automático**: GitHub Pages con CI/CD automático
- **Performance**: Estáticamente generado con Next.js 14
- **Accesible**: Cumple con estándares WCAG AA

## 📋 Secciones

1. **Hero**: Propuesta de valor clara con CTAs
2. **Features**: Características para clientes y negocios
3. **How It Works**: 3 pasos del proceso + Niveles de gamificación
4. **CTA**: Sección de conversión
5. **Footer**: Enlaces y redes sociales

## 🎨 Paleta de Colores

- **Primary**: #E65100 (Naranja)
- **Secondary**: #FF6D00 (Naranja claro)
- **Background**: #FFF3EE (Beige claro)
- **Gamification**: Bronze, Silver, Gold, Platinum

## 📦 Tecnologías

- Next.js 14
- TypeScript
- Tailwind CSS
- GitHub Actions (Despliegue automático)

## 🛠️ Desarrollo

```bash
# Instalar dependencias
npm install

# Ejecutar en desarrollo
npm run dev

# Build para producción
npm run build

# Iniciar servidor de producción
npm start
```

## 🚀 Despliegue

La aplicación se despliega automáticamente a GitHub Pages en: `https://adelgadillog.github.io/volta-app-web/`

El workflow de GitHub Actions se ejecuta automáticamente en cada push a `main`.
